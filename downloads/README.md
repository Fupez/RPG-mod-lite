# RPG Playable 0.1.0 download

Open `rpg-playable-0.1.0.jar` above and use GitHub's **Download raw file** button.

Requires Java 21, Minecraft 1.21.10, Fabric Loader 0.19.5+ and Fabric API 0.138.4+1.21.10. Put the JAR alongside Fabric API in your instance's `mods` folder. For multiplayer, install both on the server and each client.

This is the verified installable mod, not the sources JAR. The accompanying SHA-256 file identifies the exact tested build.
